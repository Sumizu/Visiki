# 调整编辑器面板

拖动左侧素材栏右缘、右侧属性栏左缘，可分别调整两侧面板宽度；拖动底部时间线上缘，可调整时间线高度。鼠标悬停分隔线时会显示调整提示，拖动到面板外松手也会结束操作。

双击分隔线可恢复对应面板的默认尺寸。左侧栏仍可用原有按钮折叠，展开后恢复所选宽度。

也可以按 Tab 聚焦分隔线，再用键盘操作：

- 左右面板使用左、右方向键；底部时间线使用上、下方向键。
- 每次调整 10 px，按住 Shift 调整 40 px。
- Home / End 到达当前窗口允许的最小 / 最大尺寸。
- Enter 恢复对应默认尺寸。

尺寸保存为本机编辑器偏好，刷新和重启后保持；拖动面板不会改变工程、生成内容撤销记录或改变导出尺寸。窗口缩小时面板会自动限制范围，确保预览和时间线仍可使用；扩大窗口后可恢复原先偏好。面板内的素材、属性和轨道仍可滚动。
