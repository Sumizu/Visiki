# 音乐频谱样式

选择“音乐频谱”组件，在右侧“可视化样式”中切换：

- **条形频谱**：按真实频段能量显示条形。
- **心电单曲线**：一条心电图风格的脉冲线，音乐中的瞬态形成短肩部与正负尖峰，从右侧向左扫描。安静段回到平静细线，只绘制开放描边，没有填充或阴影。
- **交错双曲线**：原“波浪曲线”。两条有主次的平滑曲线随音乐交错流动，粗细略有区别，形成自然的跟随节奏。两端收束，只绘制开放线条，没有填充、阴影或额外基线。静音时曲线收束为细线。
- **振幅包络**：滑动时间窗口内的真实音乐振幅，形成圆润收束的轮廓、细描边与轻薄填充。上下轮廓略有区别，强拍保留层次，避免锯齿和平顶。
- **环形频谱**：沿圆周排列频谱。

三种曲线均沿用“动效颜色”和“响应强度”，可用“曲线精细度”调整采样细度，并提供以下控制：

| 参数 | 适用样式 | 范围与作用 |
| --- | --- | --- |
| 动态平滑 | 三种曲线 | 0–100%，值越高，音乐起伏的回落越柔和 |
| 线条粗细 | 三种曲线 | 0.5–8 像素；交错双曲线的跟随线保持较细 |
| 扫描视窗 | 心电单曲线 | 0.25–4 秒；显示最近一段音乐，视窗越短，尖峰向左移动越快 |
| 流动速度 | 交错双曲线 | 0–3 倍；0 时停止横向相位流动，振幅仍响应音乐 |
| 包络视窗 | 振幅包络 | 0.25–4 秒；从左侧过去到右侧未来显示音乐起伏 |

组件的宽高决定曲线的活动区域，位置、旋转、总透明度、时间区间和轨道显隐沿用组件设置。曲线和描边保留边缘空间，缩小组件或提高响应强度时仍保持在组件范围内。

曲线由实际音乐的线性振幅控制大小，频段变化参与波浪轮廓设计，轻声段不会被自动抬到满幅。时间插值和响应／回落平滑减少逐分析帧的跳动，波浪相位连续流动，音乐开头和结尾平滑收束。这是经过设计的音频可视化，不是逐采样的原始声波示波器。

运动按歌曲时间计算，不依赖已播放的帧数；暂停调参、任意跳转和逐帧导出使用相同算法。平滑结果按音乐和参数缓存并限制内存占用。

旧工程的样式标识与原参数保持可读，原有 `wave` 样式仍对应“振幅包络”，`dual-wave` 对应改名后的“交错双曲线”，新增 `ecg-wave` 对应“心电单曲线”。这次为双曲线更改界面名称，原有双曲线的绘制和参数保持；未设置的新参数使用默认值，不需要重新导入音乐或重建轨道。条形和环形样式沿用原算法。
