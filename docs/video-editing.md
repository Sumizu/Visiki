# 图片来源与视频编辑

## 背景与卡片分开选图

在“素材”中导入多张图片，分别使用某张图片的“用作背景”和另一张的“用作卡片”。这两个操作只改变对应图层；继续上传图片不会替换已选来源。多个同类图层可逐个选中，在右侧“图片来源”选择自己的图片。

“跟随默认封面”是明确的共享选项；“未选择图片”保持未选状态。旧工程打开时，原有背景和卡片会绑定到当时的封面，保留外观，并允许以后独立修改。唱片仍可选择默认封面或独立图片。

## 视频素材和时间线

1. “导入视频”支持多选 MP4 / MOV / WEBM / MKV，以及本机 FFmpeg 能解码的其他视频。导入后显示缩略图、时长和尺寸。
2. 将播放头定位到需要的位置，点击素材的“添加视频”。同一文件可以重复添加，每个片段可独立移动、裁切、调速、倒放、显隐与变换。添加到工程结尾后方或拉长片段时，总时长会按需要延长。
3. 拖动时间线片段中部改变起始时间；拖动左右把手裁掉源视频头尾，也可以向外恢复尚未使用的源画面。倒放时裁切对应的是倒放后的可见头尾。
4. 将时间线工具切为“速率拉伸”，再拖动把手，保持源范围并改变片段长度/速度。也可按 Alt 临时拉伸。画面尺寸拉伸使用画布控制点或右侧宽高，与时间拉伸独立。
5. 把播放头放在片段内部，选择“播放头处分割”或按 Ctrl+B。分割保留当前源范围、速度和倒放状态，左右片段可以继续各自编辑。

时间线长度 =（源出点 − 源入点）÷ 播放速度。右侧“播放速度”允许 0.1–8 倍，“源入点/源出点”选择文件范围，“倒放视频”按逆序读取同一范围。裁切/拉伸有一工程帧的最短长度，分割点两侧均需保留至少一帧。

连续拖动会作为一次撤销操作。移动、分割、来源、速度、倒放及图层显隐都会保存在 `.visiki.json` 中。视频文件保留在 `.demo-data`，工程 JSON 本身不嵌入媒体。

## 移动其他画面组件

图片、背景、唱片、歌词、频谱、播放器装饰和曲目信息也可以拖动时间线片段中部，整体改变出现区间并保持时长；超出原工程结尾时会按需延长工程，最长 3600 秒。拖动左右端点调整该组件的出现区间。锁定图层须先解锁。

拖动默认对齐工程帧，并吸附到播放头或其他片段边界；Alt 可临时关闭移动吸附。整个拖动可一次撤销/重做，也可直接修改右侧起点。歌词时间仍与主配乐同步，移动歌词图层只改变显示区间。

## 视频非等比拉伸

视频的“视频适配”新增“拉伸至组件尺寸（可变形）”：完整源画面映射到图层宽高，不裁掉边缘。将宽度或高度单独改变，原画面的圆形会变成椭圆。新加入的视频默认使用此模式；旧工程仍保留原来的适配设置。

另有“填充并裁切”（等比填满，超出部分被裁掉）和“完整显示”（等比缩放，可能留空）。画布调整尺寸时按 Shift 保持当前宽高比；时间线“速率拉伸”只改变时长和速度，与画面变形独立。

## 超级键式色度抠像

选中视频图层，在“色键抠像”中打开“启用色键抠像”，选择绿幕、蓝幕或自定义键控颜色；支持的浏览器也可使用吸管从屏幕取色。与键色接近的画面变透明，显示下方的图片、视频或其他图层；图层顺序决定背景。

- 容差：提高时去除更宽的相近颜色范围。
- 边缘柔和：调整保留区域与透明区域之间的过渡。
- 溢色抑制：减少前景边缘残留的键色。

可在暂停画面直接调参，预览和导出共用同一处理流程，设置可保存和撤销。通常先选实际背景色，再逐步增加容差，最后调整边缘和溢色。效果属于本项目独立实现的色键处理，并非嵌入 Adobe 效果插件。参数设计参考 [Adobe Ultra Key 官方说明](https://helpx.adobe.com/premiere/desktop/add-video-effects/effects-and-transitions-library/ultra-key-effect-parameters.html)。

## 工程时长与声音

工程设置可调整总时长，最长 3600 秒；缩短会裁切越界片段并移除完全位于范围外的片段，可以撤销。播放按工程时钟运行，超过配乐尾部后继续播放画面；没有配乐时也能播放和导出。A1 控制主配乐静音，移除配乐可生成静音视频。

本版视频只作为画面素材使用，视频原声不加入试听和导出；请将需要的声音导入为主配乐。暂未提供多音轨剪接、音频混音、关键帧和片段转场。

视频导入时规范化为 30fps 的 H.264 MP4，等比限制在 1920×1080 边界内。单文件不超过 512 MB，源视频最长 60 分钟。倒放使用源帧定位，预览可能受多路视频解码性能影响；导出逐帧等待目标画面，速度取决于机器与素材。
