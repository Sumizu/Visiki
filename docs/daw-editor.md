# DAW 音轨编辑

当前开发版支持独立 DAW 界面、音轨编辑、试听与 WAV 混音导出。除 18 种内置音频效果外，轨道与主输出已可试用扫描登记的 VST3 音频效果。详见 [VST3 试用](daw-vst3.md)。

## 使用

在欢迎页选择 DAW，也可以用顶部标签切换工作区。离开当前工作区时暂停试听。

- 点击“添加音频”或将多个文件拖入时间线，每个文件默认新建音轨。也可通过轨道属性“添加片段”或素材库把同一素材再次插入现有轨道。
- 拖动片段移动，垂直拖到其他轨道改变所属；拖动两端裁切原素材范围。编辑保留源文件，可撤销。
- 单击或拖动时间刻度定位游标，也可在轨道空白处拖动定位。游标与片段两端可吸附到附近的片段边缘、播放游标和自适应时间网格，绿色辅助线显示对齐位置；选择片段或轨道后按 Ctrl+B 切片。片段属性也可输入位置和结束时间。
- 片段支持增益、淡入、淡出和边缘淡化手柄。两个片段重叠并分别设置淡出 / 淡入可构成简单交叉淡化。
- 轨道支持音量、左右位置、M 静音、S 独奏。音轨栏与混音器显示真实峰值 / RMS、峰值保持和削波提示，使用 dBFS 对数刻度。主输出计量位于主推子之后、试听音量之前。主输出音量参与导出；底部试听音量只影响监听。
- 拖动音轨栏右边缘、属性栏左边缘、混音器上边缘调整大小。尺寸自动限制并独立记忆，不进入工程撤销记录。双击或按 Enter 复原；聚焦分隔线后使用方向键微调，Shift 加快，Home / End 到最小 / 最大值；拖动中 Esc 取消。
- 时间刻度虚线贯穿整个音轨区与下方空白；自动模式随缩放细分，固定音符模式保持所选时值；只绘制当前可见范围。
- 导出包含全部未静音轨道，忽略临时独奏状态。生成的立体声 24-bit WAV 可下载，也可以点击「导入剪辑」，直接用作剪辑工程的主音轨。

## 标尺、吸附与自动返回

音轨栏右上角的“时间 / 小节”切换标尺显示。小节模式在工程名称下显示 BPM 和拍号，支持 20–300 BPM，常见拍号包括 2/4、3/4、4/4、6/8。BPM 按四分音符计速；拍号决定每小节长度。网格与步进自动按小节、拍或细分拍适应缩放，奇数拍号不会逐渐偏离小节线。更改这些参数不会拉伸、移动音频；参数参与工程撤销，并随会话保存。旧工程默认 120 BPM、4/4。

工具栏“网格细分”可选择：自动、一小节、全音符、二分音符、四分音符、八分音符、十六分音符、三十二分音符、六十四分音符；“时间线选项”中提供同一设置。

- **自动**：按当前标尺模式与缩放自动选择网格步长。
- **固定音符**：按工程 BPM 计算，不随缩放或时间 / 小节标尺切换而改变吸附与方向键步进精度。例如 120 BPM 的四分 / 八分 / 十六分音符分别为 0.5 / 0.25 / 0.125 秒。
- **一小节**：同时按 BPM 和拍号计算。它与全音符不同，例如 3/4 拍的一小节是三个四分音符，全音符仍为四个四分音符。

选择固定细分后，时间模式也会显示 BPM / 拍号，便于确认时值。缩小时过密的刻线会简化显示，吸附精度保持不变。网格细分在本机记忆，不改动已有片段或占用工程撤销历史。

工具栏“吸附”按钮明确显示开关，N 可切换。“时间线选项”中可分别启用 / 关闭网格、片段边缘与播放游标吸附；关闭总开关后自由定位与移动，Shift 可临时绕过。标尺显示模式与吸附偏好独立记忆在本机，不写入音频编辑历史。

底部“自动返回（Auto Return）”控制停止后的游标行为：

- **关闭 · 保持位置**：暂停 / 停止保留播放位置，再播放接着听。
- **开启 · 返回起点**：暂停 / 停止回到手动放置的游标，再播放重复试听该位置。播放中的青绿色虚线标记这一起点；在播放中手动定位，会把新位置设为下一次的起点。

播放 / 暂停按钮、Space 和停止按钮遵循所选方式。Home 是明确回到工程零点的操作。自然播放结束后，再次播放时，“自动返回”开启时仍从所选起点开始；“自动返回”关闭时从头开始。该选项在本机独立保存。该术语与 [Ardour 的 Auto Return](https://manual.ardour.org/ardours-interface/main-menu/Transport-menu/) 一致，也常称“停止时返回播放起点”。

Windows / Linux 桌面版已移除 Electron 默认的 File / Edit / View / Window 菜单。它原先只是自动隐藏，Alt 会将它唤出；因此会打断 Alt+滚轮的缩放体验。现有剪辑 / DAW 工作区页签与内置操作按钮继续使用，无需再增加重复导航。没有拦截 Alt 键或系统组合键。实现依据：[Electron Menu 文档](https://www.electronjs.org/docs/latest/api/menu#menusetapplicationmenumenu)。

## 快速分析 BPM 与拍号

导入音频后，点击顶部“分析节奏”，会自动估计当前所选片段的节奏；未选片段或片段不足 6 秒时使用素材范围。可以更换素材、指定源起点与分析时长，每次分析 6–90 秒。勾选“仅分析所选片段”会限制到该片段的源范围，不受它在工程中的开始位置影响。

结果提供 BPM、半速／倍速按钮与速度候选，支持手动微调。拍号依据重音规律给出建议；没有足够证据时显示“暂不能可靠判断”，保留当前拍号。结果中的清晰度／规律性是算法内部评分，不代表统计正确率。变速、自由速度、切分和弱鼓点音乐请结合试听确认；本次结果是全局单一速度参考，不生成逐小节速度图，也不自动对齐首拍。

点击“应用到工程”才更新 BPM 和勾选的拍号，同时切换小节标尺。它不移动或拉伸音频，支持一次撤销，参数随会话保存。关闭、取消或分析失败均不改工程。分析使用本地音频缓存，在独立工作线程运行；重复区间会使用缓存，无需联网或另装 Python／模型。

## 工程与素材

DAW 会话文件为 `.visiki-daw.json`，与剪辑工程分开。会话保存素材 ID 和编辑数据，不包含音频或波形数组。自动保存使用独立本机存储键，退出页面时同步保存已恢复完成的会话。

本地音频及派生波形位于数据目录的 `daw/sources`，默认 `demo/.demo-data/daw`。请保留这份素材库；仅复制会话文件到其他机器不能带走音频。失联时会显示提示，可恢复原素材库，或删除失联片段后重新导入；当前没有自动重链接工具。静音的失联轨不阻断其他轨试听或混音导出。

导入保留原采样率与单 / 双声道，以 Float32 WAV 缓存，不沿用视频页的固定 16-bit 标准化。单文件不超过 512 MiB、最长 60 分钟；当前每会话最多 32 轨、512 片段、64 素材。新建工程默认 48 kHz。多声道输入会明确拒绝。

## 混音和插件

可在音轨、片段和主输出上使用内置效果；兼容的 VST3 效果可挂在音轨或主输出。混音可以导出 WAV，或送到剪辑工作区继续配画面。

参见 [内置效果](daw-built-in-effects.md) 和 [VST3 插件](daw-vst3.md)。
