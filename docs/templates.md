# 预设模板

在左侧打开“模板”，查看使用当前工程素材渲染的静态缩略图，点击“应用”。模板卡只显示预览与 01–06 序号，已移除名称、简介和标签。模板适配当前画布尺寸，不改变工程时长、帧率或画布比例。

| 序号 | 布局 |
| --- | --- |
| 01 | 封面与黑胶唱片、双语滚动歌词 |
| 02 | 纯色留白、大号单句歌词，无前景封面 |
| 03 | 清晰全屏背景、底部字幕，无前景封面 |
| 04 | 全屏胶片背景、左侧滚动歌词，无前景封面 |
| 05 | 光束与薄雾背景、大字双语歌词，无图片或唱片 |
| 06 | 小封面、较大字体与心电单曲线 |

应用时保留音乐、音轨静音与效果、歌词和时间偏移、歌词来源、歌名歌手，以及所有图片、视频和字体素材。需要图片的模板使用默认封面；只有图片库而没有默认封面时使用第一张图片。模板 03／04 遇到工程已有有效视频背景时，沿用它的视频来源、播放速度、倒放、循环和适配设置；不会擅自把素材库首个视频改作背景。模板 02／05 不依赖图片，没有封面也可直接使用。

“保留现有视频和文本轨道”默认开启。这些用户轨道保留原有位置、时间区间、调速／倒放及效果，显示在模板组件上方。取消后仅替换画面轨道，素材仍在库中。再次应用其它模板会替换上一套模板生成的组件，不会反复累积装饰层。

每次应用只占一个撤销步骤，可用 Ctrl+Z 完整恢复原布局，Ctrl+Y 重做。应用后，各组件仍可拖动、显隐、排序，字体和效果也可继续调整；保存工程会记录当前模板产生的实际组件和所有后续编辑。

预览使用当前工程的歌名、歌词和封面。缩略图是静态画面，保留的视频使用当前已加载帧；应用后的实际播放和导出按时间轴求值。超过轨道容量时，可取消保留选项，或先减少用户轨道后再应用。

浅色和极简模板使用“纯色”背景。选择背景轨道后，可在“背景类型”中切换图片、视频或纯色，并修改背景色。
