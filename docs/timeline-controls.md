# 时间轴轨道操作

## 调整轨道高度

拖动每条轨道底部边缘，可以独立调整该轨道的高度，范围为 24–160 像素。片段显示区域和音频波形会跟随轨道高度变化。双击边缘恢复默认高度：画面轨道 24 像素，主音轨 36 像素。

轨道高度保存在本机编辑器偏好中，刷新或重启后保留；不写入工程 JSON，也不占用工程的撤销记录。调整底部整个时间轴面板的高度，仍使用面板最上方的分隔线。

## 拖动轨道调整图层顺序

拖动左侧轨道名称旁的排序手柄，可以上下调整图层叠放顺序。插入线表示放下后的位置，屏幕上方的轨道显示在画面前方；左侧图层列表会同步更新。鼠标靠近轨道列表上下边缘时，列表会自动滚动。

一次拖动算一次工程操作，可以撤销、重做，排序会随工程保存。排序保持组件的位置、参数和片段时间不变。锁定的轨道需先解锁才能拖动；其他轨道可以放到锁定轨道前后。主音轨固定在底部。

轨道排序从左侧手柄开始；片段主体仍用于水平移动时间位置，两端把手仍用于调整起止时间。视频的 Alt＋片段边缘速率拉伸操作保持原有行为。

## Alt＋滚轮缩放

鼠标放在时间轴上，按住 Alt 并向上滚动可放大时间刻度，向下滚动可缩小，范围为 100%–500%。缩放以鼠标所在时间点为中心，已经横向滚动后也能保持定位。鼠标位于固定轨道名称列时，以可见时间区域的左缘作为缩放中心；到达时间轴边界时会限制滚动范围。

不按 Alt 时，滚轮仍用于滚动轨道；原来的缩放滑块和加减按钮仍可使用。时间轴缩放只影响编辑视图，不改变组件尺寸、播放时间、工程内容或导出画面。
