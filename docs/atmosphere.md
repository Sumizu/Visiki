# 光影氛围组件

在左侧“组件”中点击“光影氛围”，添加一个独立的光影图层。光泄漏、薄雾和光束由程序绘制到透明画面上，完全离线运行，不需要下载视频、图片或其他外部特效素材。

## 类型与预设

| 氛围类型 | 预设 | 画面用途 |
| --- | --- | --- |
| 光泄漏 | 暖色边光、冷色光斑 | 在边缘叠加缓慢变化的柔和光斑 |
| 薄雾 | 清冷薄雾、暖色烟霭 | 叠加多层流动的柔雾纹理 |
| 光束 | 窗边斜光、放射光束 | 从指定光源位置展开一组柔边光束 |

每个组件选择一种类型；需要同时使用薄雾和光束等组合时，可添加多个组件。新组件自动使用不同的随机种子。

切换“氛围类型”或“氛围预设”时，会一次重置该预设的外观与运动参数，保留当前随机种子、淡入淡出、图层透明度、变换和时间线区间。各项设置随工程保存，可通过撤销恢复；滑块连续拖动算一次修改。

## 色彩与叠加

- **氛围强度**：0–100%，控制光影的整体强弱；0% 隐藏效果。
- **氛围主色、辅助光色**：分别设置两种颜色，光斑、雾层或光束按所选颜色组合。
- **氛围混合方式**：正常、滤色、添加。正常按透明度覆盖下方内容；滤色用于柔和提亮；添加产生更强的亮部叠加。光泄漏和光束默认滤色，薄雾默认正常。

组件本身的“不透明度”仍可独立调节。混合效果取决于当前图层下方的画面；将光影移到文字上方时，也会影响文字。

## 各类型形态参数

| 类型 | 参数 | 范围与含义 |
| --- | --- | --- |
| 光泄漏 | 光泄漏覆盖 | 0.2–4 倍，控制光斑覆盖尺度 |
| 光泄漏、光束 | 光源横向位置、光源纵向位置 | 0–100%，相对于组件自身宽高定位光源 |
| 薄雾 | 雾密度 | 0–100%，控制雾层浓淡 |
| 薄雾 | 雾纹理尺度 | 0.2–4 倍，控制纹理尺度 |
| 光束 | 光束展开角 | 5–150°，控制整组光束张开的角度 |
| 光束 | 光束数量 | 2–20 束 |
| 光束 | 光束长度 | 0.2–2 倍，相对于组件对角线的覆盖长度 |
| 光束 | 光束宽度 | 0.2–4 倍，控制各束光的宽度 |
| 全部 | 氛围柔边 | 0–100%，控制边缘柔化程度 |

光源位置和角度以组件自身坐标为准，再随组件的移动、尺寸和旋转一起变换。光影绘制范围限制在组件矩形内，可调整组件尺寸控制覆盖区域。

## 运动、分布与出入场

“运动与变化”提供氛围运动速度、方向和变化幅度：速度范围为 0–3 倍，设为 0 可保持静止；方向范围为 −180° 至 180°，光泄漏显示为“光斑朝向”，光束显示为“光束朝向”，薄雾显示为“氛围运动方向”。变化幅度控制光斑和光束的摆动与变化，以及薄雾的飘动幅度。

展开“出入场与分布”，可设置 0–3 秒的氛围淡入时长和淡出时长。两个过渡分别跟随组件的时间线起点和终点；若片段太短，会按比例缩短两个过渡。随机种子范围为 1–999999；点击“重新分布”更换种子，只改变分布，不修改其他参数。

运动使用 **组件局部时间 = 工程当前时间 − 组件起点**。移动组件后，光影随新的起点开始；任意跳转无需从头播放。相同参数、种子和局部时间对应相同画面，预览和导出共用渲染逻辑。

## 图层与时间线操作

新组件默认覆盖工程全幅，并插在最后一个背景图层上方、其他前景图层下方。可以在画布中移动、缩放、旋转，在属性中精确调整尺寸和透明度；也可以拖动时间线片段或两端调整出现区间，通过轨道眼睛控制显隐、拖动轨道排序改变叠放顺序。每个实例拥有独立参数和轨道，可以分别锁定或隐藏。

推荐先把光影放在背景上方、歌词下方，再调低强度和透明度。此组件提供二维光影氛围，不自动识别画面中的人物遮挡或真实光源。
