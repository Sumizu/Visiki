# 歌词平面朝向与文字自发光

透视重做版以 preview.7 为基线，恢复原矩形选区、四角缩放、旋转手柄和矩形命中检测。选择歌词图层，在右侧“文字平面朝向”调整左右朝向（−75° 至 75°）及透视强度（0–300%，默认 50%）。朝向 0° 保持原来的直接绘制；改变强度不改变原文、译文的独立字号或字重。

新的离轴相机保留 v7 的立体倾斜观感。相机观察方向固定为 15°，每行以自身可见宽度计算近远深度，不再依赖整首歌最长句、译文或标点的宽高比。各行中线方向一致，播放状态、滚动和切句只影响排版位置，不影响透视规则。强度增大时近侧逐渐放大、远侧缩小，中心缩放和中线角度保持不变。强度 0% 是该观察方向下的平行投影，不产生近远大小差；上方“旋转”仍可调整整个组件的画面内角度。

技术上先绕 Y 轴旋转字形，再从相机 `C=(0,-f*tan(15°),-f)` 将射线投到 `z=0` 平面。令字形宽度为 W、强度为 P，则 `f=W*(100+P)/(2*P)`；P=0 使用连续的平行投影极限。屏幕坐标为 `X=x*cos(yaw)/(1+x*sin(yaw)/f)`、`Y=(y-x*sin(yaw)*tan(15°))/(1+x*sin(yaw)/f)`。原文、译文、播放中与未播放样式遵循相同的端点近远比例。不同长宽比的字形边缘会自然汇聚，不再通过强制所有上下沿斜率相同而改变镜头距离。

标题与文本框可在“出入场动效”选择淡入淡出、上移、下移、左移、右移、缩放，默认关闭。“淡入淡出时长”为每段过渡的时长，支持 0.05–3 秒，默认 0.5 秒。动效跟随组件的时间线起止点，短组件自动缩短过渡；主副标题、多行文本和光晕整体过渡。选区保持原矩形，预览、任意定位及导出都按工程时间求值。详见 [文本与背景说明](text-and-background.md)。

文本框、曲目信息和歌词图层都有各自的“自发光”组。开启“启用自发光”后，可分别调整：

- 发光颜色：独立于文字本身的颜色，默认白色。
- 发光强度：0–200%，默认 100%；0% 不显示光晕。
- 发光范围：0–80 px，默认 18 px；越大光晕扩散越远。

文字本体仍保持清晰，描边和阴影可与发光组合。曲目信息的设置作用于曲名和副标题；歌词设置作用于原文、译文和滚动行，并继承各行的不透明度与过渡效果。

矩形选区保持组件的逻辑宽高，不随文字投影、字号或播放位置变形。歌词不再受这个矩形裁切，所选行数中的最上行、最下行及放大的近侧字形可完整显示；超出部分仍受最终视频画布边界限制。选中、移动和缩放继续通过原矩形及其四角操作。文本框和曲目信息保留原来的裁切规则。

旧工程默认朝向 0°、关闭发光。滑块一次拖动可一次撤销，所有新参数随工程 JSON 和自动保存恢复；预览和 MP4 导出使用同一套效果。透视采用有界的项目像素离屏表面，极大图层会降低表面采样密度以限制内存，不影响字号和工程尺寸参数。
