# 三段压缩与卷积混响首版方案

目标：补齐分频动态控制和基于固定脉冲响应的空间效果。两项都做成独立的内置效果，沿用现有效果链的预设、A/B、撤销、实时试听和 WAV 导出。

| 效果 | 首版操作 | 处理方式 |
| --- | --- | --- |
| 三段压缩 | 低／中／高三个可切换编辑区，两个可调分频点；每段阈值、比例、启动、释放和补偿；分段实时衰减、整体混合与输出增益 | 24 dB/oct Linkwitz–Riley 分频。低段对齐高分频点的相位，三段单位增益重组时幅度平坦。干湿混合使用同一分频重组作参考，避免与原始干声直接叠加产生抵消。首版是最小相位分频，不增加固定样本延迟，但有分频处的相位变化。 |
| 卷积混响 | 四个内置空间：录音间、室内乐厅、板式风格、大厅；预延迟、混合、湿声低切、高切和输出增益 | 每种空间有独立的早反射、扩散时间与亮度，IR 为自制双声道合成。按工程采样率准备 IR，使用分块 FFT 卷积，处理线程只累加有信号的频域块。48 kHz 下的固定处理延迟为 512 样本，由宿主补偿；预延迟仅作用于湿声。切换空间在后台准备新图，并交叉淡化。 |

首版不含用户 WAV IR 导入、线性相位分频、外部侧链或共享发送。参考 [Linkwitz–Riley 重组特性](https://docs.juce.com/develop/classjuce_1_1dsp_1_1LinkwitzRileyFilter.html) 和 [分块卷积](https://docs.juce.com/master/classjuce_1_1dsp_1_1Convolution.html)；使用 Visiki 现有 C++ 栈，不引入 JUCE。

验收顺序：参数与旧工程兼容 → 分频重组、单段压缩和分块一致性 → 卷积冲激响应、尾音、轨间对齐 → 播放中切换空间 → 独立窗口和 WAV 导出。
