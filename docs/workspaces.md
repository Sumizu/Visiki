# 工作区分页

启动后从欢迎页选择「剪辑」或「DAW」。进入后可用顶部标签切换，点击左上角的 Visiki 返回欢迎页。

- **剪辑**：保留当前音乐视频编辑器的全部功能，素材、属性、预览与时间线在同一视图内。
- **DAW**：独立多轨音频编辑与混音工作区，支持导入、移动、裁切、切片、淡化、音量、声像、静音 / 独奏、会话保存与 WAV 导出。音轨和主输出可串联内置音频效果与兼容的 VST3 效果。详见 [DAW 音轨编辑](daw-editor.md)、[内置音频效果](daw-built-in-effects.md)和 [VST3 试用](daw-vst3.md)。

工作区首次打开时才加载。切换分页时保留已经打开的工程、选择、撤销记录和布局。返回剪辑时停在离开时的播放位置。

离开工作区时暂停试听，快捷键由当前工作区处理，已经开始的导出可在后台继续。剪辑 MCP 在首次进入剪辑时连接。DAW MCP 可通过 `visiki_daw_activate` 从欢迎页进入 DAW。详见 [DAW MCP](daw-mcp.md)。

在 DAW 生成 WAV 后，点击「导入剪辑」将这份混音设为剪辑工程的主音轨，并切换到剪辑工作区。可按 Ctrl+Z 撤销导入。

顶部分页支持鼠标点击，也支持聚焦后按左右方向键、Home、End 切换。非活动面板隐藏并禁用焦点，切换分页本身不进入工程撤销记录，也不修改工程文件格式。

## 开发入口

`src/workspace-shell.tsx` 管理欢迎页、顶部分页及混音交接，按需加载 `src/App.tsx` 和 `src/daw/workspace.tsx`。工作区打开后保持挂载，分别管理工程、播放及撤销。

`src/workspace-context.ts` 仅传递当前视图是否活动及顶部栏高度，不承载剪辑工程。剪辑器依据活动状态暂停试听、释放交互视频预览资源、注册快捷键；自动保存、MCP 连接及已启动的导出不依赖当前分页。面板尺寸计算扣除顶部栏占用的高度，原左右栏和时间线拖动逻辑沿用。
