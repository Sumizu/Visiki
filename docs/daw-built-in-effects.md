# DAW 内置音频效果

DAW 现有 18 种内置效果，可插入单个音频片段、整条音轨或主输出，参与实时试听和 WAV 混音导出。

## 使用

1. 切换到顶部 **DAW**，导入音频并选择一条音轨。
2. 只处理一小段时，把游标分别放在起点和终点，用 **Ctrl+B** 切开。选中中间片段，在右侧 **片段效果链** 中添加，或从顶部 **效果库** 选择该片段。轨道效果作用于整条轨道，主输出效果作用于所有未静音音轨的混合声音。
3. 点击效果名称打开独立编辑窗口。桌面版使用独立原生窗口；浏览器版使用弹出窗口，弹出窗口被阻止时在编辑器内打开。
4. 常用参数直接显示，其余参数在“高级参数”中展开。旋钮支持拖动、键盘和数值输入；一次连续拖动算一次撤销。窗口与主编辑器共用同一份效果实例、会话和撤销历史。
5. 在效果链中切换旁路、上移 / 下移、复制或删除。信号从上到下处理，顺序会改变声音。每条链最多同时启用 12 个实例，含旁路实例最多保留 64 项。

片段上的效果随片段移动和保存。复制或切开已经挂载效果的片段时，新片段继承一套独立的效果参数。片段混响和延迟的尾音收在片段边界内。

窗口中的 A / B 用来比较两套参数，可将当前状态复制到另一槽再调整。出厂预设、重置、旁路和 A / B 切换都能撤销。“保存为我的预设”将参数保存在当前应用档案中；自定义预设列表不会自动跟随工程发送，但效果实例当前参数和 A / B 状态会随 `.visiki-daw.json` 保存。

要做等响度比较，先切换一次 A / B 或复制当前设置，准备两组参数。把播放游标放在有代表性的声音处，点击「等响度 A/B」。系统对同一段最多 5 秒的混音分别测量综合响度，在播放时仅衰减较响的一侧。分析背景运行，可在暂停时使用；测得的响度代表这段采样，其他段落或长混响尾音的响度可能不同。按钮再次点击、效果窗关闭或改变混音参数后恢复普通监听。响度补偿不写入工程，不影响表头与导出。

## 混响进阶

混响预设覆盖小录音间、鼓房、室内乐厅、楼梯间、人声板式、配乐大厅、大教堂、暗色隧道和流动氛围。预设通过同一个反馈延迟网络生成不同的反射与尾音。旧工程加载时，未保存的高级参数仍使用原版混响的默认值。

要让混响在人声之后稍晚出现，可以增加预延迟；要让尾音更密集，可以提高扩散；若低频在乐句停止后还堆积，可以降低低频衰减比例，或提高低频分界。低频衰减比例为 1× 时不额外缩短低频尾音。空间图展示早反射时间和尾音的大致轮廓。

## 去噪

学习使用该插槽的实际音频输入。选区用于估计噪声，处理范围由当前效果的挂载位置决定。挂在片段上的去噪从该片段内取样，也只处理该片段。处理曲线随工程和 A/B 一起保存。通过「试听移除声」检查是否误删了辅音、鼓点或尾音。

去嗡声适合稳定的 50 或 60 Hz 电源嗡声，也可处理它们的整数倍频。低音乐器也会占用这些频率，建议从较少的谐波开始，必要时降低去嗡强度。去混响估计并压低晚期拖尾。重混响录音仍可能保留明显的空间声，衰减过强会损伤尾音。一个实例内的三个开关可独立启用。叠加时，信号依次经过频谱去噪、去嗡声和去混响，混合滑块及移除声试听作用于整体。

频谱去噪和去混响各有 2048 个采样的处理延迟，在 48 kHz 下各约 42.7 毫秒，由工程自动补偿。去嗡声的固定处理延迟为 0。踏板音色的过采样补偿为 16 个采样，Lo-Fi 磁带风格补偿约 6 毫秒。调制中的变延迟和磁带抖动属于音色的一部分，会保留在输出中。

## 回避触发

在「固定深度」下，触发轨过阈值便按设定深度压低伴奏，检测点位于触发轨的效果、声像和音量推子之前。旧工程中的回避继续使用固定深度。

在「动态平衡」下，插件比较触发轨和当前声音的短时 RMS，并计入两路音量推子。已有足够电平差时保持原音量，伴奏偏响时增加衰减。默认目标是人声领先 3 dB，可在高级参数调整。衰减受「最大衰减」限制，停顿后按保持和释放时间恢复。窗口会显示两路比较电平和实际衰减。触发取样位于触发轨自身效果和声像之前。

「频段回避」在设定中心频率和 Q 值的附近检测两路电平，再对伴奏施加钟形衰减。较高的 Q 让影响范围更窄。可以先从「人声频段让位」预设开始，在整段混音中调节中心频率和最大衰减。

动态平衡和频段回避的「平滑人声触发」使用触发音轨的宽带 RMS。短停顿保持平滑，长停顿释放到原电平。频段回避另用目标频段的能量决定衰减量。自动混音默认启用此开关。

将人声和伴奏放在不同音轨，便可单独指定触发源。静音的触发轨暂停触发，试听时也遵循独奏选择。触发音轨随工程和 A/B 设置保存。

## 音色匹配 EQ

打开参数 EQ 中的「音色匹配 EQ」。待处理素材默认是 EQ 的挂载位置，挂在片段上就分析该片段，挂在音轨上则从轨内多个片段取样。也可指定单个片段作为分析样本。可以拖入本地音频、拖动片段上的音符图标，或从下拉框选择工程片段。时间轴缩得较小时，选中片段后可从右侧属性栏拖动「拖作 EQ 参考」。参考文件只用于当前窗口的比较，无需加入时间轴。

点击「试听参考」在窗口里播放参考干声，工程片段按裁切范围试听。参考轨可以静音。分析最多使用每侧 8 秒音频，去除整体电平差，按六个频率估算宽带补偿。需要对比中间的乐句时，可以先切出该段。

「应用匹配曲线」初始使用 60% 强度。手调 EQ 和动态设置可继续编辑，匹配曲线及强度随工程、预设和 A/B 保存。优先选择同类素材，例如同一人声的两次录音。把完整歌曲用作单条人声的参考，容易让伴奏的频谱左右结果。

## 自动混音

在 DAW 顶部打开「自动混音」，选择不同的主唱和伴奏轨，两轨都需要有音频且未静音。和声可以选「无和声」。可设置人声位置、曲风、人声空间和成品电平。选中和声轨后可以设置和声用途，其中「混合」模式支持试听、修改或添加接唱区间。

主唱和和声默认使用门限／扩展器、多频段参数 EQ、压缩和去齿音。主唱在链首加入频谱去噪。有稳定停顿时会学习底噪并轻量抑制。缺少可用样本时，插件等待用户在去噪窗口手动学习底噪。「人声空间」控制短立体声延迟和混响，选「保持原样」或强度为 0 可省略这两项。EQ 窗口会同时显示各启用频段的类型、频率与增益或斜率。

和声轨上的动态平衡由主唱触发，主唱停唱后平滑恢复。动态平衡之后加入轻量合唱调制和立体声宽度调整。伴奏声像居中但左右电平持续失衡时，使用立体声工具轻调偏响声道。其余情况使用参数 EQ 浅削低中频。伴奏轨上的频段回避继续由主唱触发，主输出默认使用真峰值保护与计量。

既有轨道效果和主输出效果在分析、新方案试听与应用时旁路，实例和参数会留在原效果链。所有新插件插入音轨或主输出，片段设置与片段效果继续生效。「原工程」试听使用应用前的效果。确认应用记为一次编辑，Ctrl+Z 可恢复旧效果的启用状态和原先的推子。

段落可使用建议区间或自定义最多 20 秒。三个版本使用相同的工程区间，响度匹配只作用于监听。取消某条建议后，可重新计算其余调整。导出 WAV 会复测实际响度、真峰值和超限采样。

## 信号顺序与导出

含有效果实例的会话由独立 C++ 原生音频进程处理，试听与导出共用 `native/dsp.h` 的同一套算法。音频设备回调只读取预先计算好的音频环形缓冲；DSP、文件访问和控制消息在设备回调之外处理。原生宿主读取导入后的 Float32 WAV 缓存，采样率不同时重采样到工程采样率。

信号从片段增益、淡化与声像进入片段效果链。对齐后的各片段先在轨道内混合，再经过轨道效果、轨道音量和轨间对齐。轨道混合进入主输出音量和主输出效果链，最后用于试听或导出。限幅器位于主输出音量之后，调大主输出音量会增加其驱动量。试听音量只控制监听。

前瞻限幅、过采样与卷积混响引入的已知延迟会在轨道间补偿，导出时移除总处理延迟。卷积混响在 48 kHz 下的处理延迟是 512 个采样，约 10.7 毫秒。预延迟是湿声的一部分，会保留在试听和导出中。普通参数连续调整使用平滑处理；更换卷积空间时后台准备新响应并交叉淡化。

WAV 导出使用点击导出时的固定工程快照，输出 24-bit 立体声 PCM，并在量化时加入微量抖动。混响 / 延迟的估计尾音最多保留 30 秒；极长反馈的余音可能在该上限处结束。独奏只影响试听，导出包含全部未静音音轨。没有效果实例时仍可使用 FFmpeg 基础混音路径导出；在原生试听不可用时回退至流式试听。

导出忽略 EQ 频段独听、门限与去齿音的检测独听、去噪移除声试听，以及立体声工具的单声道检查和监听模式。旧工程仍可用这些控件试听；如果原先用它们有意改变 WAV 的声道，请改用「声道转换（写入导出）」。增益、声道交换和低频单声道等正常处理仍参与导出。

WAV 完成后显示综合响度（LUFS）、真峰值（dBTP）和超限采样数。响度和真峰值测量最终 WAV；超限采样统计量化前绝对幅度大于 1 的样本，左右声道分别计数。采样点之间的峰值也可能使真峰值超过 0 dBTP，即使超限采样数为 0。短音频或信号未达到响度门限时，综合响度显示为未测得。

峰值、压缩衰减和频谱来自实际信号；插入的分析器使用 libebur128 计算响度和真峰值。效果示意图根据参数绘制：压缩传递曲线计入干湿混合和补偿，去齿音图显示检测带通与最大抑制，延迟图分左右声道，饱和图显示所选算法的静态响应。

## 工程兼容与当前范围

旧 DAW 会话未包含效果字段时可直接打开。效果类型、参数范围、预设标识和实例 ID 在读取会话时校验，未知或不完整的效果数据会提示错误。关闭效果窗口不会删除效果，删除效果或关闭所属会话后窗口不再修改该实例。

回避插件提供从其他工程音轨读取的侧链触发。Windows x64 可通过效果库扫描第三方立体声 VST3 效果，并与内置效果一同插入音轨或主输出。详见 [VST3 试用](daw-vst3.md)。剪辑页的画面效果与 DAW 音频效果分别保存，DAW 效果操作见 [DAW MCP](daw-mcp.md)。

## 开发与分发

原生宿主目前面向 Windows x64。开发者第一次构建或修改原生源码后需要 Visual Studio C++ Build Tools（MSVC x64 和 Windows SDK），并安装项目的 Node 依赖。`npm run build` / `npm run dev` 先比较原生源码与宿主的 SHA256，缺失或过期时才调用编译器；未变化的预编译宿主可直接复用。

```powershell
npm run build:native   # 显式重新编译并记录指纹
npm run check:native   # 只检查源码、宿主和记录是否匹配
npm run test:native    # 编译并运行独立 DSP 检查
npm run build          # 检查 / 更新宿主，并构建界面与服务
```
