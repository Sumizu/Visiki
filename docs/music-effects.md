# 音乐联动与通用过渡

## 音乐呼吸／频段联动

选中画面组件，在左侧“效果”添加“音乐呼吸／频段联动”。全频、35–250 Hz 低频、250–4000 Hz 中频、4000–16000 Hz 高频和自定义频段均可作为驱动；可用频率受音频采样率及现有 16 kHz 分析上限约束。

“灵敏度”放大输入能量，“触发阈值”过滤轻微声音。“响应时间”和“回落时间”分别控制升起与回落的速度；0 表示即时响应。“缩放幅度”和“亮度幅度”使强音时组件变大、变亮；“透明度变化”使强音时组件更透明，默认 0。可以重复添加实例，让低频控制缩放、高频控制亮度。

驱动取自既有离线 FFT 缓存，使用真实频率映射和线性幅度，缓存响应与回落包络；包络缓存最多 4 MiB，不保留已关闭工程的分析数据。按歌曲全局时间采样，暂停、乱序跳转、组件移动和视频导出不会改变同一时刻的结果。没有音乐、分析未完成、主音轨静音或歌曲结束时保持原画；音轨淡入淡出也会减弱联动。试听音量是监听控制，不参与视频画面和导出音量计算。

## 淡入淡出

可添加到任意画面组件或主音轨 A1。淡入、淡出分别可设 0–10 秒，0 关闭对应的一端；短于两端时长之和的片段会按比例缩短过渡。“整体强度”用于混合原始状态与过渡结果，关闭或设为 0 可旁路效果。

画面支持普通透明度、上移、下移、左移、右移和缩放，移动距离可独立调整；曲线可选平滑、线性或正弦缓入。所有文字、投影和自发光整体过渡，编辑选区保持原矩形。处理按效果列表顺序执行，和调色、胶片等其他效果可混合排序。

非滚动歌词还可将过渡范围设为“每句歌词”。每个原文／译文块一起过渡，结束时间取下一句、SRT 显式终点、组件终点和工程终点中最早的值；歌词偏移同时作用于过渡。SRT 空白段保持空白。滚动模式忽略每句过渡，可改用“组件出入场”让整个歌词组件进入或离开。

## 音频淡入淡出

点击 A1 或拖动“淡入淡出”到 A1，在右侧效果页调整时长和曲线。音轨只改变音量，画面位移和缩放参数不会作用于音乐；可选平滑、线性或等功率曲线。多项淡入淡出叠乘，静音优先。

音轨从歌曲 0 秒开始，淡出在歌曲实际时长与工程时长中较早的终点结束。改变工程时长时会同步更新；只导出歌曲中间的一段不会重新淡入，也不会在该导出区间末尾额外淡出。预览采用同一包络计算音量，FFmpeg 使用逐采样表达式完成导出。试听音量滑块仅影响监听。

## 旧工程

打开旧工程时，文字／曲名出入场、歌词逐句切换及光影氛围的淡入淡出自动转换为独立效果，并关闭对应旧参数，避免叠加两次。重复保存、刷新和重开不会重复迁移。若旧轨道已有 8 项效果，则保留原绘制与旧过渡；界面给出说明，可腾出一个位置并重新打开工程完成迁移。原有已发布的 preview.12 ZIP 保持不变，本轮更新开发目录。
