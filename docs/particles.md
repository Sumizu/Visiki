# 氛围粒子组件

在左侧“组件”中点击“氛围粒子”，即可添加独立的粒子图层。新组件默认覆盖当前工程画面，放在背景上方、其他前景下方；可以移动、调整宽高、旋转、改变总透明度，也可以添加多个组件叠加不同效果。每次新增组件使用不同分布种子。

## 六种样式

- 星尘：缓慢漂浮的细小光点，适合抒情背景。
- 萤火：带柔光、轻微游动和明暗变化的光点。
- 飘雪：向下飘落并随风摆动的雪点。
- 细雨：带方向和长短变化的雨线。
- 花瓣：程序绘制的旋转花瓣，无需额外素材。
- 散景：柔边、半透明的大光斑。

切换样式会应用该样式的默认参数，并保留随机种子和组件的变换、总透明度、时间区间。切换样式可以一次撤销。

## 参数

可以调整粒子数量、大小、速度、风向、摆动、颜色、粒子透明度、闪烁和随机种子。负风向向左，正风向向右。粒子大小以工程像素为单位；组件总透明度与粒子自身透明度叠加生效。不同样式对闪烁、摆动的表现各有区别。

相同参数和种子在相同组件局部时间下得到相同画面。修改种子会换一组分布；复制图层会保留原分布，如需不同粒子位置，可再修改副本的种子。粒子运动受组件矩形范围限制，边缘会渐隐。

## 时间线、预览与导出

粒子组件有自己的时间线片段，可以拖动片段、调整起止时间、复制、删除、排列层级，以及通过轨道眼睛切换可见性。移动片段会保留组件内部的动画时序；组件仅在开始时间至结束时间之间显示。

把粒子放在背景上方、封面和歌词下方，可避免遮挡文字；也可放在最上方作为前景装饰。粒子无需音乐或媒体素材，可以在无配乐工程中使用。

预览、任意进度跳转和导出共用同一套粒子渲染。粒子按绝对局部时间生成，暂停和重导出不会重新随机。柔光使用有内存上限的小纹理缓存，不需要联网或下载额外素材。当前粒子不包含音频响应、碰撞或三维物理。
