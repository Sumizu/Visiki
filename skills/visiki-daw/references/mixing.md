# 混音与试听

先听有代表性的主歌、密集段和结尾，判断人声可懂度、伴奏遮蔽、声像、噪声与动态。先做小幅电平和平衡调整，再针对具体问题使用内置均衡、压缩、去噪或空间效果。降低噪声时检查齿音和尾音是否受损，压缩要保留演唱起伏，混响不能掩盖歌词。保留用户要求的特殊音色和已有处理，不为追求响度牺牲动态。效果参数和预设按当前 catalog 确认，不假定固定数值适合所有素材。

比较前后版本时尽量匹配监听响度，避免把更响误当成更好。对单个效果可建立 A/B 状态，使用 `visiki_daw_monitor_effect` 的 `action:"compare"` 进行等响度监听。`action:"noise"` 试听去噪去除的内容，完成后用 `action:"clear"` 清除监听。`visiki_daw_meters` 读取实际播放设备的电平，暂停时轨道数据可能为空。最终还应试听渲染文件，检查明显削波、爆音和结尾。

自动混音需要不同的主唱轨和伴奏轨，两轨须含有片段且未静音。把真实轨道 ID 传给 `options.roles:{lead, backing}`。有和声时可指定另一条有效轨道作为 `roles.harmony`，此时才使用和声用途和接唱区间。默认 `harmony:"support"`、`direction:"natural"`、`genre:"none"`、`space:"room"`、`spaceAmount:25`，交付默认 `delivery:{mode:"preserve",ceilingDb:-1,targetLufs:-14}`。这些是程序默认值，不是用户选择的目标。根据用户意图显式选择，用户未要求空间处理时可用 `space:"unchanged"`。若轨道结构不满足要求，手动处理或使用其他相关分析。

自动混音分析输出计划并不修改工程。检查计划、分段、提示和变化后，使用同一任务的 `original`、`balance`、`full` 试听，按需指定结果中实际的 `changeIds`。`balance` 只选推子变化，`full` 包含选中的其他变化。应用任一方案会旁路已有的所有启用轨道效果与母线效果，片段效果仍保留，即使只应用 balance 也如此。先确认该结果符合用户意图，再调用 `job_apply`，需要保留现有效果时改用有针对性的手动编辑。应用后重新检查工程和试听，不把自动计划视为质量保证。

减少计划中的处理项目后，如有明确的交付响度或峰值目标，用 `excludedChangeIds` 重新分析，使建议电平基于所选处理。以最终导出测量为准。
