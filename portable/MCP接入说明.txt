MCP 接入

普通用户直接启动Visiki即可使用编辑器，可以忽略本说明。

1. 将整个发布包解压到本地文件夹，不要直接在压缩包内运行，也不要只复制部分文件。无需安装 Node.js，无需管理员权限。
2. 双击“启动Visiki.cmd”，等待编辑器打开，并在使用 MCP 期间保持编辑器运行。
3. 双击“生成MCP配置.cmd”，当前文件夹中会生成“MCP配置.json”。可以重复运行，文件会更新为当前解压位置。
4. 打开所用 agent 客户端的 MCP 设置，添加一个本地 stdio 服务。支持 JSON 配置的客户端，可将“MCP配置.json”中的 visiki 项合并到客户端现有的 mcpServers 中，不要覆盖已有的其他服务。不同客户端的配置格式可能不同，请保留其中的 command、args、env。
5. 重新连接 MCP 服务。剪辑工具在首次进入剪辑后就绪。使用 DAW 时选择 DAW 工作区，或调用 visiki_daw_activate。DAW 工具可编辑会话和效果、分析和试听混音、导出 WAV 并送到剪辑。MCP 操作会同步到界面。

如果客户端以表单配置：
- command、args、env 分别填写“MCP配置.json”中的对应值；不要省略 ELECTRON_RUN_AS_NODE=1。
- 或将本目录的“启动MCP.cmd”作为 stdio 启动入口。该文件供客户端调用，双击不会弹出编辑器。

注意：
- 移动或重命名解压目录后，重新运行“生成MCP配置.cmd”，并更新客户端中已保存的路径。
- 先打开编辑器，再连接 MCP。连接信息由编辑器自动生成，无需复制令牌。
- MCP 可以修改当前工程和发起导出；开始前可先保存工程。
- 退出编辑器后 MCP 暂时无法控制工程，再次打开后可重连。
- 配置脚本只更新本目录的“MCP配置.json”，不会自动更改任何客户端设置。
